# Rich3 Editor 介面規格

> 這份文件記錄本專案介面的**實際數值與行為**。改動畫面時先看這裡，改完回頭更新這裡。
> 撰寫規則見 [docs/rules/INTERFACE_RULES.md](docs/rules/INTERFACE_RULES.md)。

> ⚠ **目前是唯讀的地圖檢視器。** 版型、共用元件樣式與圖示字體繼承 `RICH2_EDITOR`（見
> [ADR-0002](docs/adr/0002-inherit-rich2-editor-appearance.md)）。可以選資料夾、選地圖、
> 看圖、點格子；**沒有任何寫入功能**，復原／重做與「儲存到遊戲」維持 `disabled`，
> 地價以下五個頁籤仍是佔位。仍未定的項目標示為**未定**，實作時填入，不要刪除章節。

---

## 1. 適用範圍與視窗尺寸

| 項目 | 值 |
| :--- | :--- |
| 畫面型態 | 編輯工作站（三欄），繼承 `RICH2_EDITOR` |
| 預設尺寸 | 1500 × 950（邏輯像素） |
| 最小尺寸 | 1180 × 700 |
| 可否縮放 | 可 |

設定在 `src-tauri/tauri.conf.json`。尺寸暫時沿用 `RICH2_EDITOR`，實作後依實際需要調整。

⚠ 尺寸一律以**邏輯像素**為準。高 DPI 下量測時，量測工具本身必須是 DPI 感知的。

## 2. 色票

全部沿用 [docs/rules/tokens.css](docs/rules/tokens.css) 的共用 token（**必須共用**，不得自訂）。`src/style.css` 的 `@theme` 只做引用，不複製色值。

| Token | 色值 | 用在哪 |
| :--- | :--- | :--- |
| `--color-background` | `#131313` | 視窗底色 |
| `--color-surface-container-lowest` | `#0e0e0e` | 最底層面板 |
| `--color-surface-container-low` | `#1b1b1c` | 面板底色 |
| `--color-surface-container-high` | `#2a2a2a` | 次要按鈕、分頁 |
| `--color-surface-container-highest` | `#353535` | hover |
| `--color-surface-bright` | `#393939` | 最上層元素 |
| `--color-on-background` | `#e5e2e1` | 主要文字 |
| `--color-on-surface-variant` | `#c0c7d3` | 次要文字 |
| `--color-outline-variant` | `#404751` | 邊框、分隔線 |
| `--color-primary` | `#9fcaff` | 焦點框、強調 |
| `--color-primary-container` | `#007acc` | 主要按鈕 |
| `--color-on-primary-container` | `#ffffff` | 主要按鈕文字 |
| `--color-tertiary` | `#66dd8b` | 成功訊息 |
| `--color-error` | `#ffb4ab` | 錯誤訊息 |
| `--color-level-warn` | `#fcd34d` | 警告訊息 |

**本專案額外定義的色**：

| 名稱 | 色值 | 為什麼不用共用 token |
| :--- | :--- | :--- |
| `--color-selection` | `#e51400` | 方塊網格的選取框。共用 token 沒有對應語意（`primary` 已用於主要動作），而選取框要在密集的網格上一眼可辨。與 `RICH2_EDITOR` 同值。 |

除此之外**不得硬寫色值**，一律用 token。

## 3. 字體與字級

字體堆疊沿用共用 token（**必須共用**）。字級表屬**建議共用**，本專案採用標準表、未偏離。

| 用途 | 字級 | 字重 | 行距 | 字體 |
| :--- | ---: | :--- | ---: | :--- |
| 應用程式標題 | 16px | bold | 1.2 | sans |
| 區塊標題 | 14px | medium | 1.4 | sans |
| 內文 / 按鈕 | 14px | normal | 1.5 | sans |
| 欄位標籤 | 12px | normal | 1.4 | sans |
| 次要說明 | 11px | normal | 1.5 | sans |
| 路徑 / 數值 / 日誌 | 11px | normal | 1.6 | mono |

- 同一列的控制項字級必須相同。
- 不得使用表外的字級。

**圖示字體**：Material Symbols Outlined，自帶於 `src/assets/fonts/`（6.5 KB 子集，取自
`RICH2_EDITOR`，不連 CDN）。⚠ 只能用子集內已有的圖示——本專案沒有產生子集的工具，
用了子集外的名稱會直接在按鈕上顯示 `folder_open` 這種英文字。目前用到：
`folder_open`、`undo`、`redo`、`save`、`terminal`。

---

## 4. 間距

| 名稱 | 值 | 用於 |
| :--- | ---: | :--- |
| 視窗外緣 | 20px | 內容距視窗四邊（上下左右一律相同） |
| 區塊間 | 12px | 主要區塊之間 |
| 控制項間 | 8px | 同一列的控制項之間 |
| 標籤與欄位 | 6px | 欄位標籤與輸入框之間 |
| 區塊內邊距 | 10px | 面板內容距邊框 |

- **四邊外緣必須相等**，不得單獨加大某一邊。
- 不得使用表外的值。

> `RICH2_EDITOR` 因為三欄同時顯示而把外緣改成 16px 並多一檔 4px。本專案先用標準值，等版型定案後若真的排不下再依規範記錄偏離與理由。

---

## 5. 控制項

| 項目 | 值 |
| :--- | :--- |
| 標準高度 | 36px |
| 緊湊高度 | 28px |
| 圓角 | 6px |
| 水平內邊距 | 至少 12px |

同一列的控制項**必須等高、字級相同**，寬度可不同。

### 按鈕角色

| 角色 | 外觀 | 用於 |
| :--- | :--- | :--- |
| 主要 | 實心，`--color-primary-container` 底 | 每個畫面唯一的主要動作（預期是「儲存到遊戲」） |
| 次要 | 透明底，`--color-outline-variant` 描邊 | 其餘動作 |

### 按鈕狀態

| 狀態 | 表現 |
| :--- | :--- |
| hover | 主要提亮 10%；次要底色加深一階 |
| active | 不做位移，只加深 |
| disabled | 不透明度 40% + 禁止游標（來自共用 token） |
| 進行中 | 改文字並停用 |

---

## 6. 視覺效果

### 不透明度

只使用共用 token 的五檔（**必須共用**）：

| 檔位 | 值 | 用於 |
| :--- | ---: | :--- |
| 主要 | 100% | 主要文字、實心元件 |
| 次要 | 70% | 次要文字 |
| 提示 | 50% | 提示文字、placeholder |
| 停用 | 40% | 停用狀態 |
| 分隔 | 25% | 分隔線、邊框 |

### 光暈 / 模糊 / 漸層

| 效果 | 是否使用 | 用途與強度 |
| :--- | :--- | :--- |
| 光暈（box-shadow 發光） | **未使用** | — |
| 高斯模糊（backdrop-filter） | **未使用** | — |
| 漸層 | **未使用** | — |

層次一律靠 `surface` 色階表現（已有 6 階）。

### 影像渲染

實作地圖或圖集預覽時**必須**用 `image-rendering: pixelated`。遊戲素材是 16 色 4 Plane 的像素圖（見 [docs/INFORMATION.md](docs/INFORMATION.md)），平滑縮放會糊掉。

---

## 7. 狀態與回饋

| 狀態 | 表現 |
| :--- | :--- |
| 焦點 | 2px `--color-primary` 外框、偏移 2px，走 `:focus-visible`（來自共用 token） |
| hover | 見 §5 |
| 停用 | 不透明度 40% + 禁止游標（來自共用 token） |
| 載入 / 進行中 | **未定** |
| 錯誤 | 寫進右欄的操作記錄面板（比照 `RICH2_EDITOR`），**不跳對話框** |

⚠ **禁止**在任何元件上寫 `outline: none` 而不補替代樣式。共用規則是零特異度的 `:where()`，任何 class 都蓋得掉它。

### 訊息等級

名稱與配色屬**必須共用**，與 Rich 系列其他專案一致：

| 等級 | 顏色 |
| :--- | :--- |
| `INFO` | `--color-on-surface-variant` |
| `WARN` | `--color-level-warn` |
| `ERROR` / `FATAL` | `--color-error` |
| `SUCCESS` / `DONE` | `--color-tertiary` |

實作在 `src/ui/log.ts`，樣式是 `src/style.css` 的 `.log-<等級>`。等級**不得自行增減**：
少一個等級，同一件事在兩支程式裡就會被寫成不同的字，使用者回報時對不起來。
面板保留最新 500 則，並且是整個介面唯一可以選取文字的區域（要能複製出來回報問題）。

## 8. 畫面結構

版型繼承 `RICH2_EDITOR`（[ADR-0002](docs/adr/0002-inherit-rich2-editor-appearance.md)）。
版型雖屬「各自決定」，但兩支工具同一個使用者會前後腳用到，相同的版面省下重學一次。
頁籤的**內容**依《大富翁3》自己的資料重新切，**框架不動**。

```text
┌──────────────────────────────────────────────────────────────────────┐
│ Rich3 Editor  [選擇遊戲資料夾][地圖▾][比例▾] 狀態 [↶][↷] [儲存到遊戲]│ 56px
├──────────────────────────┬──────────────────┬────────────────────────┤
│                          │ 屬性面板         │ 格子資訊               │
│   地圖畫布               │ ┌──────────────┐ ├────────────────────────┤
│   （可縮放，            │ │地圖│地價│股票│ │ 操作記錄        [清除] │
│     pixelated）          │ └──────────────┘ ├────────────────────────┤
│                          │  頁籤內容        │  INFO 編輯器已啟動     │
│                          │                  │  WARN …                │
│                          ├──────────────────┤                        │
│                          │ [頁籤層級的動作] │                        │
├──────────────────────────┴──────────────────┴────────────────────────┤
│ > 最新一則操作記錄            BIG5  MAP: 50x50  未載入               │ 32px
└──────────────────────────────────────────────────────────────────────┘
   flex-1                    28rem 固定        18rem 固定
```

| 區塊 | 職責 |
| :--- | :--- |
| 頂部工具列 | 程式名稱；選資料夾 → 選地圖 → **選檢視比例** → 復原／重做 → 儲存到遊戲。主要動作（儲存到遊戲）只有這一個 |
| 地圖畫布 | 50×50 的 `TileGrid`。backing store 2400×2400（48px × 50），顯示尺寸由縮放模式決定 |
| 屬性面板 | 固定 28rem。頁籤：地圖／地價／股票／事件／卡片／角色，各對應一組資料檔（見下表） |
| 格子資訊 | 點到哪格顯示哪格，會整塊覆寫 |
| 操作記錄 | 只往下累加，不被格子資訊洗掉。500 則上限 |
| 底部狀態列 | 左：最新一則操作記錄；右：編碼、地圖尺寸、載入狀態 |

**面板寬度是硬約束。** 頁籤放不下時**橫向捲**（兩側箭頭 + 隱藏捲軸），不得把面板撐寬——
撐寬會擠掉地圖畫布。

### 地圖的檢視比例

| 檔位 | 顯示尺寸 | 用途 |
| :--- | ---: | :--- |
| `Auto`（預設） | 容器短邊 | 一眼看完整張圖 |
| `50%` | 1200 × 1200 | 每格 24px，圖案還認得出來 |
| `100%` | 2400 × 2400 | 1:1，驗證細節 |

比例超出容器時由主區域捲動（`overflow: auto`）。

⚠ **畫布一律由程式算出實際像素尺寸寫到元素上，不得改用 `object-fit: contain`。**
`contain` 會在非正方形的容器裡留黑邊，而黑邊讓「點擊座標 → 格子」多一層偏移量要算——
元素尺寸等於畫面尺寸時，換算永遠只是一個比例。

⚠ 選了 `Auto` 之後比例通常是 0.35 這種非整數，`image-rendering: pixelated` 下會有抽點鋸齒。
這是刻意接受的取捨（`RICH2_EDITOR` 同樣如此）；`50%` 與 `100%` 是整數比例，縮放乾淨。

頁籤與資料來源的對應（來源標在每頁頂端，實作時才不會找錯檔案）：

| 頁籤 | 資料來源 |
| :--- | :--- |
| 🗺️ 地圖 | `MAP.MKF` #00 地圖組成 · #01 地圖方塊集 · #02 座標地點轉換表（**已實作**，唯讀：摘要、地點形態分佈、結構檢查） |
| 💰 地價 | `MAP.MKF` #04 地價表 · #05 過路費表 |
| 📈 股票 | `MAP.MKF` #10 上市公司股票資訊 · #06 承銷資訊 |
| 📰 事件 | `MAP.MKF` #11 新聞 · #12 命運 · #08/#09 國曆與農曆假日 |
| 🃏 卡片 | `CARDDATA.DAT` · `CARD.BLK` |
| 👤 角色 | `PLAYER.DAT` · `MAP.MKF` #15 內定參與角色 |
