# Rich2 Editor

> 《大富翁2》的地圖編輯器。掛上遊戲資料夾直接讀寫原始檔，改完存檔就能進遊戲看結果。

---

## 這是什麼

《大富翁2》的地圖藏在 `Part?.pak` 與 `Save_?.dsk` 這些二進位檔裡，沒有官方編輯器。這個工具把它們解析出來，用現代介面讓你直接改：畫地圖、調價格、改地段名稱、調角色與 AI 性格，然後一鍵寫回遊戲資料夾。

**主要功能**

- **掛資料夾就能用**——選一次遊戲主目錄，編輯器自動找到並解析地圖與存檔，改完「儲存到遊戲」直接寫回，不用匯入匯出。
- **三張原版地圖**——台灣、香港、大富翁城，隨時切換。
- **地圖繪製**——貼土地、購地標記、道路與風景；框選一片格子一次套用。特殊地點（銀行、卡片店那些）點一下就配好完整的 2×2 四格。
- **價格與角色**——改地段價格與各級過路費，也能一次套用倍率標準化所有地段；改角色初始資金與 AI 的購地、增建、買股門檻。
- **缺字自動補進遊戲字型**——地段名稱可以用遊戲原本畫不出來的字，存檔時會把缺的字補進 `Wor.pak`。
- **經過就觸發**——可以讓指定的特殊地點在被經過時就停下觸發，不必剛好停在那一格。
- **結構檢查與修復**——警告頁列出方向沒接好、孤兒記錄、海路編號錯位等問題，並提供一鍵修復。
- **自動備份**——每個檔案第一次被覆寫前都會留一份 `.bak`。

## 取得與安裝

### 系統需求

| 項目 | 需求 |
| :--- | :--- |
| 作業系統 | Windows 10 以上 |
| 其他 | WebView2 執行期，Windows 10/11 已內建 |
| 遊戲 | 一份《大富翁2》，資料夾裡要有 `Run.exe`、`Part1.pak`、`Save_7.dsk` 等檔案 |

### 下載

至 [Releases](../../releases) 下載其中一個，兩者內容相同，挑順手的：

| 檔案 | 說明 |
| :--- | :--- |
| `Rich2Editor-vX.Y.Z-setup.exe` | 安裝檔。裝到使用者目錄，不需要管理員權限。 |
| `Rich2Editor-vX.Y.Z-portable.exe` | 免安裝，直接執行。 |

> ⚠ **開工前先把整個遊戲資料夾另外複製一份。** 編輯器每次覆寫前都會留 `.bak`，但那只保得住「最原始的那一份」，救不了你昨天改到一半的版本。

## 快速開始

1. 開啟編輯器，按左上角「**選擇遊戲資料夾**」。
2. 選到《大富翁2》的目錄（裡面要有 `Run.exe`）。
3. 從上方下拉選單挑地圖：**台灣 / 香港 / 大富翁城**。

載入後右下角的操作紀錄會告訴你讀到了什麼，包括**這張圖還剩幾個可用的地點編號**。

### 畫面

**左邊**是地圖，**右邊**是屬性面板，分五頁：

| 分頁 | 做什麼 |
| :--- | :--- |
| 🧱 **圖塊** | 畫地圖。貼土地、購地標記、特殊地點、道路、風景 |
| 📍 **地點** | 改目前選到那一格的編號、地段、方向、路由 |
| 💰 **價格** | 改地段的土地價格與各級過路費 |
| 👤 **角色** | 改每個角色的初始現金／存款，以及 AI 的決策門檻 |
| ⚠️ **警告** | 結構問題一覽 + 各種修復按鈕 |

**選格子**：點一下選一格；**壓住左鍵拖曳出一個方框**，框裡的格子會全部選起來（從 1,1 拖到 20,20 就是整塊 20×20）。選好之後到「圖塊」頁點一個圖塊，就會一次套用到全部。

## 操作指南

### 先搞懂五個東西

大富翁2 的地圖不是「看起來像什麼就是什麼」，格子的**編號**才決定引擎怎麼處理它。

| 名詞 | 是什麼 |
| :--- | :--- |
| **土地** | 可以買賣的地。編號一定 **≥51**，一定屬於某個地段，圖塊是 **9~14** |
| **購地標記** | 貼在土地旁邊的小旗子，編號 = **土地編號 + 950**，圖塊是 **1**。跟土地嚴格 1:1 |
| **地段** | 一組土地共用一份價格表。名稱固定 **3 個字寬**（兩個字會自動撐開，像「中　環」） |
| **特殊地點** | 銀行、卡片、公園那些。**佔 2×2 四格**，四格圖塊連號。編號從 1 開始 |
| **海上道路** | 水面上的路。編號**緊接在特殊地點之後**連號排下去，上限 50 |

⚠ **移動不是看格子相不相鄰**，而是看每個地點的「上下左右」四個方向欄位指向誰。所以兩格畫在一起不代表走得過去，方向沒接好就是走不過去。

### 新增土地

1. 在地圖上選好要放的格子（可以框選一片）。
2. 到「圖塊」頁點 **9~14** 任一個土地圖塊。

編號、座標、方向、路由都會自動配好。接著：

3. 在旁邊放一格**圖塊 1** 當購地標記（它會自動配 `+950` 的編號，並推算建築朝向）。
4. 到「地點」頁設**地段**，到「價格」頁設價格。

> 沒設地段的土地在遊戲裡買不了，警告頁會提醒你。

### 刪除

**貼一個沒有地點語意的圖塊上去就是刪除**（也就是 1、9~14、40~83、84 以外的任何圖塊，例如風景）。

刪除會一次清乾淨：格子、它的購地標記、整筆記錄、**還有所有指向它的方向指標**。最後那項最容易漏——漏了會留下指向空記錄的路徑，引擎照著走就會出事。

### 貼特殊地點

「圖塊」頁上方一種類一顆按鈕，**以目前選到的那格為左上角，一次貼滿 2×2 四格**。編號、座標、方向、路由、種類會一次配好。點在既有的特殊地點上，就是換它的種類。

> 特殊地點的數量寫在 `Run.exe` 裡，不在地圖檔。改完數量記得到警告頁按**「修復特殊」**，再存檔才會寫進去。加了特殊地點之後海路編號要整段後移，用**「修復海路」**。

### 改地段名稱與缺字

「地點」頁的地段名稱欄位。名稱固定 3 個字寬。

**遊戲自帶的字型只畫得出字表裡的字**（原版 639 個）。打了字表外的字時：

| 情況 | 編輯器怎麼處理 |
| :--- | :--- |
| 一般的字 | 🆕 **存檔時自動用細明體補進遊戲字型**，補完就正常顯示 |
| 圖庫也沒有的字 | ⚠ 提醒你換字 |
| Big5 罕用字（如「鰂」） | ❌ 遊戲的文字剖析器根本不認，**加進字表也沒用**，只能換字 |

自動補字會改到 `Wor.pak`，同樣有 `.bak` 備份。

### 改價格

「價格」頁改的是**目前選到那格所屬地段**的價格。

**地價標準化**：填好七個倍率後按「套用到所有地段」，每個地段的增值價與各級過路費都會改成「該地段的土地價格 × 倍率」，**土地價格本身不動**。

原版其實三張圖各一套：

| | 增值 | 空地 | 一層 | 二層 | 三層 | 四層 | 五層 |
| :--- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 台灣／香港 | 0.15 | 0.20 | 0.60 | 1.43 | 2.86 | 5.0 | 7.5 |
| 大富翁城 | 0.20 | 0.625 | 1.5 | 3.0 | 5.0 | 8.0 | 11.7 |

### 改角色

「角色」頁。每張圖的角色不同（台灣 4 人、香港 5 人、大富翁城 6 人）。

- **現金 / 存款**——開局時的錢。
- **其餘成對的欄位**——AI 門檻：手上的錢**多於上限就一定做、少於下限就一定不做、夾在中間則是隨機**。分別對應購地、增建、買股。

所以調這幾個數字等於在調每個角色的性格。把某個角色的購地上限調到很低，他就會見地就買。

### 警告頁

列出結構問題，點一下可以跳到出問題的格子。上面那排按鈕：

| 按鈕 | 做什麼 |
| :--- | :--- |
| **修復路由** | 修 UNKA／UNKB（警車去監獄、救護車去醫院的路線）。只修真的走不通的格子 |
| **修復特殊** | 依圖塊推算這張圖的特殊地點數，填進欄位（要存檔才寫回 `Run.exe`） |
| **修復海路** | 海路編號整段重編，接回特殊地點後面 |
| **修復地圖** | 自動修可安全修的（座標同步、清掉孤兒記錄） |

### 存檔

按右上角**「儲存到遊戲」**。一次寫回：

- `Part?.pak`（地圖、地段名稱）
- `Save_?.dsk`（地點資料、價格、角色參數、圖塊排版）
- `Run.exe`（地點上限、特殊地點數）
- `Wor.pak`（如果有缺字要補）

**每個檔案第一次被覆寫前都會自動留一份 `.bak`。**

## 常見問題

#### 開啟時出現「Windows 已保護您的電腦」或防毒警告

這支程式使用自簽憑證，沒有向憑證機構購買，因此 Windows SmartScreen 會跳出警告。若你是從本專案的 [Releases](../../releases) 頁面下載的，可以點「其他資訊」→「仍要執行」。

#### 出問題了，怎麼查？

1. **先看操作紀錄**（右下角）。編輯器每個動作都會回報做了什麼、有沒有失敗。
2. **警告頁**會列出結構問題。
3. 還是不行就整個資料夾換回你一開始複製的那份備份。

#### 改壞了怎麼還原？

把 `<檔名>.bak` 複製回去覆蓋即可。

⚠ **但 `Run.exe` 例外，不要整檔還原。** `Run.exe` 裡有三個位元組是**遊戲自己寫的**（偵測到的音效與顯示設定），整檔覆蓋會把那些一起清掉。要撤銷編輯器對 `Run.exe` 的修改，只改那幾個容量數值就好。

#### 地段名稱打了某些字，遊戲裡顯示成別的字

遊戲自帶的字型只畫得出字表裡的字。編輯器會在存檔時自動把缺的字補進 `Wor.pak`，補完就正常顯示。少數 Big5 罕用字（首位元組小於 `0xA1`，例如「鰂」）遊戲的文字剖析器根本不認，加進字表也沒用，只能換字——遇到這種情況編輯器會明講。

#### 想加東西但編輯器說沒有可用的地點編號了

引擎的地點陣列上限是 283。大富翁城那張圖 51~282 已經全部用滿，要加東西得先刪掉用不到的。載入時右下角的操作紀錄就會告訴你這張圖還剩幾個編號。

#### 存檔後遊戲裡沒有變化

確認你按的是「儲存到遊戲」而不是只在編輯器裡改。另外特殊地點的數量存在 `Run.exe` 裡而不是地圖檔，改完數量要先到警告頁按「修復特殊」，再存檔才會寫回去。

## 已知限制

- **大富翁城已經沒有可用的地點編號了**。引擎的地點陣列上限是 283，而那張圖 51~282 全部用滿。要加東西得先刪掉用不到的，載入時編輯器就會提醒你。
- **地段編號只能到 44**。PAK 的文字表只有 44 行、價格表也只有 44 組，編號 ≥45 的地段名稱與價格**沒有地方存**，在遊戲裡會沒名字也買不了。編輯器會警告。
- **Big5 罕用字補不進去**（首位元組 < `0xA1`，例如「鰂」）。遊戲的剖析器不把它當中文，會把後面整串排版弄歪。
