Rich2 Editor —— 大富翁2 地圖編輯器
=====================================

【怎麼用】
  雙擊 Rich2Editor.bat

  會跳出一個黑色小視窗（那是本機伺服器，不要關），接著自動開啟編輯器。
  關掉編輯器視窗就會自動結束。

【需要什麼】
  - Windows 10 以上
  - Microsoft Edge 或 Google Chrome（Edge 是 Windows 內建的）

  編輯器要直接讀寫遊戲資料夾，用的是只有 Chromium 系瀏覽器才有的 API，
  所以 Firefox 不行。

【第一次使用】
  1. 按「選擇遊戲資料夾」，選到大富翁2 的目錄（裡面有 Run.exe 那個）
  2. 瀏覽器會問要不要允許存取，選「檢視檔案」→「編輯檔案」
  3. 從上方下拉選單挑地圖

【備份】
  編輯器第一次覆寫任何檔案前，都會自動留一份 <檔名>.bak。

  但請注意：不要用 Run.exe.bak 整檔還原。Run.exe 裡有三個位元組是遊戲自己
  寫的（音效／顯示設定），整檔覆蓋會把那些偵測結果一起清掉。
